# Привет, сообщество **FlowSlice AI**! 🚀

Версия **0.1.0** — первый публичный релиз.

---

## ✨ Возможности
- **ИИ-ассистент-инженер 3D-печати:** эксперт по механике, Klipper и тонкой настройке материалов прямо во вкладке Orca Slicer.
- **Контекст слайсера:** модель со стола (габариты, объём, манифолд, статистика экземпляров), профили принтера/пластика/настроек печати (полный дамп параметров, заметки, start/end G-code).
- **Мультичат с историей:** персист в `data_dir()`, поиск, закрепление, авто-названия, лимит сообщений.
- **Стриминг ответов (SSE):** остановка генерации, регенерация, edit & resend.
- **Вложения:** фото (до 4 МБ, сжимаются до 1024 px) и текстовые файлы (до 100 000 символов) в контексте; для моделей без поддержки изображений выводится предупреждение, а текстовые файлы передаются как обычный текст.
- **Провайдеры:** DeepSeek, OpenRouter (включая роутеры `auto` / `auto-beta` / `free`), Google, Anthropic, OpenAI, Groq, GLM, Cerebras, Mistral, xAI; свои OpenAI/Anthropic-совместимые провайдеры — на вкладке «Персональные».
- **Настройки на 4 вкладках:** «Модели», «Персональные», «Общие значения», «Оформление»; черновик настроек применяется только по «Сохранить», сброс — только текущей вкладки.
- **Контекст в чате:** чекбоксы контекста и режим выгрузки пресетов (только изменённые / все) для пластика, принтера и настроек печати — прямо в панели чата, с запоминанием.
- **Команды:** `/context`, `/compact`, `/clear`, `/model`, `/printer`, `/stats`, `/help`, `/reset`.
- **Локализация:** English / Русский / Srpski.
- **Темизация:** авто (нативная Orca) / чисто белая / чисто чёрная, акцент `#d9534f`.

## 📲 Как установить?
1. Скачайте `flowslice_ai-0.1.0-py3-none-any.whl` внизу этой страницы.
2. В Orca Slicer откройте **Плагины → Установить локальный плагин** и выберите скачанный файл.
3. Перезапустите Orca Slicer — вкладка **FlowSlice AI** появится в главном окне.

> ⚠️ **Важно:** `numpy` — необязательная зависимость (extra `deep`): она включает глубокий анализ
> геометрии модели, но плагин полностью работает и без неё.
