# Привет, сообщество **FlowSlice AI**! 🚀

Версия **0.1.0** — первый публичный релиз.

---

## ✨ Возможности
- **ИИ-ассистент-инженер 3D-печати:** строгий эксперт по механике, Klipper и тонкой настройке материалов прямо во вкладке Orca Slicer.
- **Контекст слайсера:** модель со стола (габариты, объём, манифолд, статистика экземпляров), профили принтера/пластика/настроек печати (полный дамп параметров, заметки, start/end G-code).
- **Мультичат с историей:** персист в `data_dir()`, поиск, закрепление, авто-названия, лимит сообщений.
- **Стриминг ответов (SSE):** остановка генерации, регенерация, edit & resend.
- **Вложения:** фото (до 6 МБ) и текстовые файлы (до 1 МБ) в контексте.
- **Провайдеры:** DeepSeek, OpenRouter, Custom (OpenAI-совместимый), Anthropic-совместимые схемы.
- **Настройки на 3 вкладках:** «Модели», «Общие значения», «Оформление»; черновик настроек применяется только по «Сохранить».
- **Команды:** `/context`, `/clear`, `/model`, `/printer`, `/stats`, `/help`, `/reset`.
- **Локализация:** English / Русский / Srpski.
- **Темизация:** авто (нативная Orca) / чисто белая / чисто чёрная, акцент `#d9534f`.

## 📲 Как установить?
1. Скачайте `flowslice_ai-0.1.0-py3-none-any.whl` внизу этой страницы.
2. В Orca Slicer откройте **Плагины → Установить локальный плагин** и выберите скачанный файл.
3. Перезапустите Orca Slicer — вкладка **FlowSlice AI** появится в главном окне.

> ⚠️ **Важно:** зависимость `numpy` устанавливается автоматически при загрузке плагина.

## 🔧 Для разработчиков
- Модульная архитектура: пакет `flowslice_ai/` (движок-миксины, UI-ресурсы, конфигурация).
- Единый файл версии: `flowslice_ai/version.py` — версия меняется только там.
- Сборка wheel: `python -m build --wheel` (в wheel попадают только модули пакета).
- QA: `pylint` + `pyright` + `pytest` — обязательный гейт перед релизом.
