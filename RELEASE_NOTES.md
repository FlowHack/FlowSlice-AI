# FlowSlice AI 0.1.3 🚀

## 🆕 Что нового

- **Заголовок провайдера в списке моделей виден всегда:** даже если активен только один провайдер
  или все избранные модели взяты из одного провайдера, группа провайдера подписывается отдельно —
  путаницы между «Избранным» и остальным списком больше нет.
- **Кнопка очистки поиска:** в полях поиска чатов и поиска модели/провайдера появился крестик ✕ —
  один клик стирает весь запрос. Кнопка показывается только когда в поле есть текст.

## 📲 Как установить?

**Способ 1. Как плагин из каталога OrcaCloud**

1. Откройте [страницу FlowSlice AI в OrcaCloud](https://cloud.orcaslicer.com/p/3dfa96ca82dd).
2. Оформите подписку и установите плагин.
3. Перезапустите Orca Slicer — вкладка **FlowSlice AI** появится в главном окне.

**Способ 2. Локальная установка `.whl`**

1. Скачайте whl файл внизу этой страницы.
2. В Orca Slicer откройте **Плагины → Установить локальный плагин** и выберите скачанный файл.
3. Перезапустите Orca Slicer — вкладка **FlowSlice AI** появится в главном окне.
